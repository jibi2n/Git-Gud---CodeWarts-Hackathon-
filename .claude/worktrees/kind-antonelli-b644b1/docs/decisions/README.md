# Architecture Decision Records

One file per significant decision, named `ADR-NNN-short-description.md`.

Template:

```markdown
# ADR-NNN: <title>

- **Status:** proposed | accepted | superseded by ADR-XXX
- **Date:** YYYY-MM-DD
- **Owner:** <role>

## Context
What is the situation that forces a decision?

## Decision
What did we choose?

## Consequences
What follows — good and bad?

## Alternatives Considered
What did we rule out, and why?
```
